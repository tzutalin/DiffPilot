# DiffPilot Proprietary License Design

## Goal

Add a repository license that protects the DiffPilot project, including source code used to host its website, while allowing visitors to access and use the hosted site for its intended purpose.

## Approach

Use a custom proprietary license rather than an open-source license. The license identifies DiffPilot as the copyright holder and reserves all rights.

## License Terms

The root `LICENSE` file will:

- State `Copyright © 2026 DiffPilot. All rights reserved.`
- Permit visitors to access and use the hosted DiffPilot website for its intended purpose.
- Retain DiffPilot ownership of source code, design, branding, content, and associated materials.
- Prohibit copying, redistribution, modification, derivative works, reverse engineering, and commercial use without prior written permission.
- Include standard "as is" warranty and liability disclaimers.

## Scope

This is a repository license only. It does not create website Terms of Service, a privacy policy, or a customer agreement.

## Validation

Review the final `LICENSE` file to ensure the copyright holder, year, permitted hosted-site use, prohibited actions, and disclaimer are present.
