Privacy policy

Effective November 14, 2026

Short version: DiffPilot does not collect, store or sell any information about you. There are no accounts, analytics, advertising or tracking.

What the app keeps on your Mac

DiffPilot saves your settings, review comments, reviewed marks and recent projects in ~/Library/Application Support/dip on your Mac. This data never leaves your computer through DiffPilot. You can delete it at any time by removing that folder.

What the app does not do

  • No analytics, telemetry, crash reporting or usage tracking.
  • No advertising and no advertising identifiers.
  • No accounts, sign in or servers run by DiffPilot.
  • The only request DiffPilot makes on its own is a weekly check with Apple's App Store lookup service for a newer version. It sends DiffPilot's app identifier, your country and the current time, nothing about you or your code, and you can turn it off in Settings.
  • No sharing or selling of data with anyone.

Tools you choose to connect

Some features run other programs that you install and sign in to yourself. When you use them, those programs talk to their own services under their own privacy policies:

  • Git runs on your Mac. Fetching or pushing contacts the remotes you configured.
  • GitHub CLI (gh): loading or reviewing a pull request sends requests to GitHub using your own gh sign in. See the GitHub privacy statement.
  • Coding agents such as Claude Code, Codex, Gemini CLI or OpenCode: when you ask an agent to review, explain, polish or fix, DiffPilot sends that agent the relevant diff, file paths and comments. The agent may send that content to its AI provider. Review your agent's privacy terms before using these features.
  • Your editor (VS Code or Zed) opens when you choose to open a file in it.

DiffPilot never sends anything to these tools unless you take an action that uses them, and you can turn GitHub and agent features off in Settings.

This website

This site is hosted on GitHub Pages. It uses no cookies, analytics or third party scripts, and its fonts are served from the same site. GitHub may log technical information such as IP addresses to operate and secure the service, as described in the GitHub privacy statement. GitHub Issues you open are public and governed by GitHub's terms.

Children

DiffPilot does not knowingly collect information from anyone, including children under 13.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
