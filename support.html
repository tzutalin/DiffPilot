What to include in a bug report

  • DiffPilot version: run dip --version, or choose DiffPilot → About DiffPilot.
  • macOS version and whether your Mac has Apple silicon or an Intel processor.
  • How you opened the review, for example dip --staged, git mergetool or a pull request.
  • Steps to reproduce, what you expected and what happened.
  • A screenshot if it's visual. Remove anything private first.

GitHub issues are public. Don't paste source code, tokens or customer data you can't share. If a report needs private details, say so in the issue and we'll find another way.

Security issues

Please don't open a public issue for a security problem. Use private vulnerability reporting on GitHub instead.

Common questions

How do I set DiffPilot up as git difftool or mergetool?

Follow the git difftool and git mergetool guides. Each is three git config commands.

The dip command isn't found

Link it onto your PATH as described in Install the command line tool, then open a new terminal window.

Pull requests won't load

DiffPilot uses the GitHub CLI. Run gh auth status in Terminal and sign in with gh auth login if needed.

My coding agent doesn't connect

Check the agent runs from Terminal on its own, then pick it again under Settings → Agent. DiffPilot includes presets for 29 agents and supports any agent that speaks the Agent Client Protocol. If the agent reports that it needs signing in, DiffPilot shows the login command for it in the panel.

Where are my comments and settings stored?

On your Mac only, in ~/Library/Application Support/dip. Delete that folder to reset DiffPilot. See the privacy policy.

How do I get a refund?

Purchases from the Mac App Store are handled by Apple. Request a refund at reportaproblem.apple.com.
